# PharmaCare – Pharmacy Management System

A full-stack web-based Pharmacy Management System developed to simplify pharmacy operations.

## Technologies Used
- Frontend: React.js, Vite, JavaScript, HTML, CSS
- Backend: Node.js, Express.js
- Database: MongoDB, Mongoose

## Main Features
- Dashboard
- Medicine Management
- Inventory Management
- Sales Management
- Customer Management
- Supplier Management
- Accounting Summary
- Reports
- User Management

## Project Description
PharmaCare helps manage medicine details, stock availability, sales records, suppliers and customers through a centralized application.

## How to Run
1. Install the required dependencies.
2. Start the backend server.
3. Start the frontend development server.
4. Open the application in your browser.
